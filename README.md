สมาชิก นายภานุวัฒน์ ทรัพย์คง 6830300649 นายณัฏชนน ดีสูงเนิน 6830300207 นายอานัส โต๊ะเฮง 6830300991



การพัฒนาเกมยิงเป้าแบบ 2 มิติด้วยภาษา Java
Java เป็นภาษาโปรแกรมเชิงวัตถุที่ได้รับความนิยมอย่างแพร่หลายในวงการเขียนโปรแกรม เนื่องจากมีความเรียบง่าย ใช้งานง่าย มีรูปแบบการเขียนโค้ดที่เป็นมาตรฐาน รองรับหลายแพลตฟอร์ม และมีเครื่องมือพัฒนามากมาย
หลักการของโครงการนี้คือการศึกษาหลักการเขียนโปรแกรมพื้นฐานของ Java ผ่านการสร้างมินิเกม เกมนี้จะเป็นประสบการณ์จริงในการเรียนรู้แนวคิดการเขียนโปรแกรม การประมวลผลเหตุการณ์ และการทำงานด้านกราฟิก
การสร้างเกมช่วยเพิ่มความสามารถของนักเรียนในการคิดอย่างมีเหตุผล สร้างโปรแกรมได้อย่างถูกต้อง และแก้ปัญหาได้อย่างเป็นระบบ ทักษะนี้จะช่วยให้บุคคลเหล่านั้นกลายเป็นนักพัฒนาที่มีประสิทธิภาพในอนาคตวัตถุประสงค์ 


วัตถุประสงค์ของโครงการมีดังต่อไปนี้

เพื่อศึกษาพื้นฐานของการเขียนโปรแกรมในภาษา Java เพื่อเรียนรู้กระบวนการพัฒนาส่วนติดต่อผู้ใช้แบบกราฟิก (GUI) เพื่อให้มีความรู้เกี่ยวกับการจัดการเหตุการณ์
เพื่อพัฒนาเกมยิงปืน 2 มิติ
ขอบเขตของโครงการ การเขียนโค้ดด้วย Java ส่วนติดต่อผู้ใช้ที่พัฒนาด้วย Java Swing เกมเล่นในรูปแบบ 2 มิติ ผู้ใช้จะสามารถเล่นเกมได้ด้วยเมาส์ ระบบการให้คะแนนและการเคลื่อนที่ของเป้าหมายได้รับการเขียนโค้ดแล้ว 
ผู้เรียนจะได้เรียนรู้การเขียนโปรแกรมภาษา Java ผู้เรียนจะได้เรียนรู้แนวคิดเกี่ยวกับส่วนติดต่อผู้ใช้แบบกราฟิกและแนวคิดเกี่ยวกับการจัดการเหตุการณ์ ผู้เรียนสามารถออกแบบและพัฒนาโปรแกรมแบบโต้ตอบได้ ความรู้ที่ได้รับสามารถนำไปใช้ในโครงการพัฒนาซอฟต์แวร์อื่นๆ ได้
