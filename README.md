#  Slime Slayer

เกมแอคชั่น 2D แนว Side-Scrolling สร้างด้วย Java Swing  
สู้กับสไลม์ 3 เวฟ เปิดหีบสมบัติ และอยู่รอดให้ได้!

---

##  วิธีเล่น

- ฆ่าสไลม์ให้หมดในแต่ละเวฟ
- เปิดหีบสมบัติเพื่อรับไอเทมสุ่ม
- เดินเข้า **Portal** ฝั่งขวาเพื่อไปเวฟถัดไป
- เคลียร์ครบ 3 เวฟเพื่อชนะ!



## สิ่งที่ต้องมีก่อนเล่น

- Java JDK 11 ขึ้นไป
- ดาวน์โหลดได้ที่: https://www.java.com/download

## วิธีรันเกม

### วิธีที่ 1 — VS Code (แนะนำ)

1. เปิดโฟลเดอร์โปรเจกต์ใน VS Code
2. ติดตั้ง Extension **"Extension Pack for Java"**
3. เปิดไฟล์ `Main.java`
4. กดปุ่ม **Run ▷** มุมขวาบน หรือกด `F5`
## 🕹️ ปุ่มควบคุม

| ปุ่ม | การกระทำ |
|------|----------|
| `A` | เดินซ้าย |
| `D` | เดินขวา |
| `W` | กระโดด |
| `Space` | โจมตี |
| `E` | เปิดหีบ (ต้องเดินเข้าใกล้ก่อน) |
| `R` | เก็บไอเทมจากหีบ |
